# FitVitta — GitHub Pages

Este é um site inicial simples para publicar o domínio `fitvitta.com.br` no GitHub Pages.

## Publicar
1. Crie um repositório público no GitHub, por exemplo `fitvitta-site`.
2. Envie o arquivo `index.html` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
5. Em **Custom domain**, informe `fitvitta.com.br` e salve.
6. No Registro.br, configure os registros DNS indicados na documentação oficial do GitHub Pages para domínio raiz.
7. Quando o DNS estiver validado, habilite **Enforce HTTPS** em Settings → Pages.

Este arquivo inicial não configura ainda o caminho `/ozenvitta`; ele serve como página inicial do domínio.
